# The Hidden Word (WordPress theme)

Marketing and demo theme for **[Hidden Word Bible Lessons](https://wordpress.org/plugins/hidden-word-bible-lessons/)** — used on [thehiddenword.org](https://thehiddenword.org) and for WordPress Playground / InstaWP live demos.

## Requirements

- WordPress 6.4+
- PHP 8.0+
- [Hidden Word Bible Lessons](https://wordpress.org/plugins/hidden-word-bible-lessons/) 2.0+ (integrated advanced features)

## Setup

1. Install and activate **Hidden Word Bible Lessons**
2. Activate this theme
3. Go to **Appearance → Marketing Setup → Run Marketing Setup**
4. Optionally set the plugin download URL under **Appearance → Customize**

Marketing Setup creates lesson, catalog, Bible reader, memorization, Verse of the Day, study finder, ask-a-question, and auth pages with `[hwbl_*]` shortcodes.
